MOONLIT DONGPO — GEMINI EDITION

1. Extract the ZIP and open the inner moonlit-dongpo folder.
2. Copy .env.example to .env in the same folder as main.go.
3. Get an eligible Gemini API key at https://aistudio.google.com/apikey
4. Edit .env and replace PASTE_YOUR_GEMINI_KEY_HERE with your key.
5. Double-click start-windows.bat or run: go run .
6. Open http://localhost:8081

If you have a server on port 8081 already, stop it first.
Never share your .env file or upload it to GitHub.
